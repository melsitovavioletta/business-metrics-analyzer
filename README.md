# Business Metrics Analyzer

Учебный проект по дисциплине «Проектирование и разработка бизнесориентированного программного обеспечения».

## Бизнес-задача

Расчёт и визуализация ключевых показателей эффективности (KPI) предприятия.

## Используемые технологии
- Python 3.10+
- Git, GitHub

## Планируемые метрики
- Средняя выручка
- Рентабельность

## Инструкция по запуску

python -m venv .venv  
source .venv/bin/activate # или .venv\Scripts\activate для Windows  
pip install -r requirements.txt  
python main.py
