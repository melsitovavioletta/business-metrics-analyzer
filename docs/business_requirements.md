### Название проекта: 
business-metrics-analyzer

### Назначение: 
расчёт и анализ ключевых показателей эффективности (KPI) предприятия на основе входных финансовых данных.

### Язык реализации: 
Python 3.10

## Цели проекта
- Автоматизировать расчёт базовых KPI
- Обеспечить воспроизводимость расчётов
- Организовать командную работу
- Заложить основу для расширения

## Функциональные требования 
- Приложение должно предоставлять функцию расчёта рентабельности.
- Приложение должно иметь файл main.py с функцией main(), в которой: задаются/принимаются входные данные (выручка, затраты); вызывается функция расчёта KPI; результат выводится в консоль.
- Репозиторий должен содержать README.md, в котором должна быть описана основная информация о проекте. 
- Все изменения должны фиксироваться в коммитах.
- Командная разработка новых функций и документации ведётся в отдельных ветках.

## Критерии качества
- Python установлен, работает python --version, создано и активировано .venv
- IDE настроена, выбран интерпретатор .venv, программа main.py запускается
- Git настроен: указаны user.name, user.email
- Создан локальный репозиторий, добавлены .gitignore, README.md, requirements.txt 
- Выполнены коммиты и push в удалённый репозиторий GitHub 
- Создана ветка, оформлен Pull Request, выполнено слияние 
- Ответы на контрольные вопросы

## Планируемые метрики 
- Средняя выручка
