## Контрольные вопросы

### 1. Чем отличается Git от GitHub? 

Git - это программа, которая работает на локальном компьютере. GitHub - это облачный веб-сервис для хранения проектов.

### 2. Для чего используется виртуальное окружение Python?

Виртуальное окружение Python используется для создания изолированной рабочей среды, которая позволяет устанавливать зависимости и библиотеки индивидуально для каждого проекта и предотвращает конфликты версий.

### 3. Что такое commit, branch, remote, pull request?

сommit - это зафиксированные изменения кода с комментарием
branch - это отдельная ветка разработки внутри проекта
remote - удаленный репозиторий, хранящийся на GitHub
pull request — запрос на слияние кода из одной ветки в другую

### 4. Зачем нужен файл .gitignore?

.gitignore - это файл, в котором указаны файлы, которые не должны попасть в репозиторий.

### 5. Как организовать командную работу над бизнес-приложением с помощью Git?

Главная версия кода хранится в ветке main. Каждый разработчик создает свою изолированную ветку и вносит изменения в общий репозиторий. Далее осуществляется pull request, чтобы объединить изменения в проекте.

### 6. Какие файлы обязательно должны быть в репозитории учебного проекта?

main.py - файл с кодом программы
README.md текстовый документ с информацией о проекте
requirements.txt - файл со списком необходимых библиотек
.gitignore - список файлов, которые не должны попасть в репозиторий

### 7. Что произойдёт, если два разработчика изменят один и тот же файл в разных ветках?

Если изменения внесены в разные части файла, то изменения объединятся. Если правки были в одних и тех же строках, то возникнет merge conflict.
